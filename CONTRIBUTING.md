# Contributing

Thank you for helping improve Surface. We welcome bug reports and feature
requests as GitHub issues. This repository doesn't accept pull requests from
outside contributors: only Straddle collaborators can open them.

## Report a bug

Open an issue that includes the following:

- The package and version, for example `@straddlecom/straddle-js@1.0.0`, and
  whether you load it from npm or the CDN.
- The browser and its version.
- The steps that reproduce the problem.
- What you expected and what happened instead.
- Any `straddleerror` event details or console errors.

Remove session tokens, API keys, and customer data before you post. Issues are
public.

## Request a feature

Open an issue that describes what you're building and what the SDK would need
to do. A use case helps us more than a proposed API.

## Get integration help

Issues are for problems in the SDK itself. For help with your integration or
your Straddle account, see [SUPPORT.md](SUPPORT.md).

## Report a security vulnerability

Don't open an issue. Follow [SECURITY.md](SECURITY.md) instead.
