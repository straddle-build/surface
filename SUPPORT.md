# Support

Use the following channels to get help with Surface:

| You need                                       | Where to go                                                        |
| ---------------------------------------------- | ------------------------------------------------------------------ |
| Help with your integration or Straddle account | Email [support@straddle.com](mailto:support@straddle.com)          |
| API reference and integration guides           | [docs.straddle.com](https://docs.straddle.com)                     |
| Answers to common questions                    | [help.straddle.com](https://help.straddle.com)                     |
| A fix for a bug in the SDK                     | A GitHub issue, as described in [CONTRIBUTING.md](CONTRIBUTING.md) |
| To report a security vulnerability             | [SECURITY.md](SECURITY.md)                                         |

When you email support, include your Straddle account ID, the package version,
and the `straddleerror` details if you have them. Never send API keys.
